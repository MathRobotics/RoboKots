# 摂動モデルの検証

このフォルダ（`examples/perturbation_example`）を作業ディレクトリにして
実行します。追加の描画・表ライブラリは不要です。

```bash
uv run python main.py
```

このフォルダの `perturbation.toml` を編集して再実行すると、質量・リンク長・
重心のノイズ量を変更できます。`seed` を固定すれば同じモデルを再現できます。
明示ルール（分布指定、質量倍率の共有、関節零点、慣性）を試す場合:

```bash
uv run python main.py --config rules.toml
```

`--config` に別のTOMLも指定できます。相対パスは実行時ディレクトリ基準です。
既定設定とモデルのパスはスクリプトの配置を基準に解決します。

## 出力と確認内容

- モデルは `examples/model/2dof_arm.json`、計算はNumPyです。
- リンク質量と、親リンクから各関節原点までの距離を比較します。
- 両モデルに同一の関節位置・速度・加速度を与え、`arm2` の原点のworld位置、
  位置ヤコビ行列、逆動力学トルクとその最大絶対差を表示します。
- この平面アームで重力トルクを確認するため、重力は両モデルとも
  world座標の `[0, -9.81, 0] m/s²` に揃えています。
- 公称モデル非破壊、ゼロ摂動での一致、同一seedでの再現、レポートのJSON往復
  による再現を検証します。失敗すると例外で終了します。
- `seed` 未指定時は同一seedの確認をスキップします。

差が出ることは正しさの証明ではなく、設定の影響を確認するための表示です。
すべての摂動を0にした場合や対象を空にした場合、差が0でも正常です。
`arm2` 原点は関節2の位置で、メッシュ先端ではありません。
剛体リンク長は出側関節原点への距離に作用するため、出側関節のない `arm2`
の長さは既定では変えません。図形・メッシュの伸縮は行いません。

このサンプルはファイルを出力しません。設定の詳細・単位・適用順は
[摂動ガイド](../../docs/perturbation.md)を参照してください。
